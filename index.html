Política de Privacidad (Español)

Última actualización: Noviembre de 2026
Aplicación: AllerTracker (com.dmorafoguet.allertracker)
Desarrollador: David Mora Foguet (dmorafoguet@gmail.com)

1. Garantía de Privacidad Local-First

AllerTracker ha sido diseñada bajo una arquitectura estrictamente Local-First. Todos los datos introducidos por el usuario (nombre, apellidos, registro diario de síntomas de rinitis/conjuntivitis alérgica, medicación habitual o de rescate y notas clínicas) se almacenan exclusivamente en la memoria interna del dispositivo del usuario (mediante SQLite/Room y Android DataStore). No disponemos de servidores propios, cuentas de usuario, bases de datos en la nube, rastreadores analíticos ni publicidad.

2. Uso del Permiso de Ubicación (GPS)

  • Finalidad exclusiva: La aplicación solicita permiso opcional de ubicación (ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION) únicamente cuando el usuario utiliza la aplicación para calcular en el propio teléfono cuál de las 10 estaciones oficiales de la Xarxa Aerobiològica de Catalunya (XAC - PIA) se encuentra más próxima mediante la fórmula matemática de Haversine.
  • No transmisión de coordenadas: Las coordenadas GPS exactas del usuario nunca se envían a ningún servidor externo. La consulta pública al boletín aerobiológico de aerobiologia.cat se realiza únicamente con el nombre del municipio de la estación oficial más cercana (por ejemplo, barcelona, tarragona, girona).

3. Datos de Salud y Generación de Informes PDF

  • Los registros de síntomas y medicación permanecen al 100% dentro del teléfono del usuario.
  • La generación del informe clínico mensual en formato PDF se realiza íntegramente de forma local en el dispositivo. El archivo PDF solo se comparte si el usuario pulsa explícitamente el botón "Compartir / Exportar PDF" y elige por sí mismo el destinatario mediante el menú nativo de Android.

4. Eliminación de Datos y Control del Usuario

Dado que todos los datos residen únicamente en el teléfono del usuario, este puede borrar registros individuales desde la propia aplicación en cualquier momento, o eliminar la totalidad de los datos borrando el almacenamiento de la aplicación o desinstalándola de su dispositivo Android.

5. Contacto

Para cualquier consulta sobre esta Política de Privacidad, puede contactar con el desarrollador en: dmorafoguet@gmail.com.

Privacy Policy (English)

Last updated: November 2026
Application: AllerTracker (com.dmorafoguet.allertracker)
Developer: David Mora Foguet (dmorafoguet@gmail.com)

1. Local-First Privacy Architecture

AllerTracker is built with a strict Local-First architecture. All personal and health-related information entered by the user (name, daily allergic rhinitis/conjunctivitis symptom logs, medication intake, and clinical notes) is stored exclusively on the user's device using local SQLite/Room and Android DataStore. We do not operate any backend servers, user accounts, cloud databases, analytics trackers, or advertising SDKs.

2. Location Permission (GPS)

  • Sole Purpose: The app requests optional location permission (ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION) strictly on-device to compute the nearest official aerobiological station from the Xarxa Aerobiològica de Catalunya (XAC - PIA) catalog using the Haversine distance formula.
  • No Coordinate Transmission: Your exact GPS coordinates never leave your device. Public forecast requests to aerobiologia.cat only include the municipality code of the nearest station (e.g., barcelona, tarragona, girona).

3. Health Data & PDF Reports

  • All symptom and medication logs remain 100% on your device.
  • Clinical PDF reports are generated locally on-device and are only shared when the user explicitly taps "Share / Export PDF" via the native Android share sheet.

4. Data Deletion & User Control

Users can delete individual entries inside the app at any time, or erase all data permanently by clearing the app's storage or uninstalling AllerTracker from their Android device.

5. Contact

If you have any questions regarding this Privacy Policy, please contact: dmorafoguet@gmail.com.
